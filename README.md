# Infinite Sports Nutrition – store demo

A demo of the Infinite Sports Nutrition WooCommerce store that runs entirely in the browser with WordPress Playground.

- Store: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/infinite-sports-nutrition-demo/main/blueprint.json
- Store admin (products, stock, orders): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/infinite-sports-nutrition-demo/main/blueprint-admin.json

Each visit builds a fresh copy (about 30 seconds), so test orders are not kept.
